ОБЛІК ПРОДАЖУ КНИГ
Python + PostgreSQL

Про проєкт
============

Це консольна програма для обліку продажу книг у книжковому магазині.

У програмі є 3 основні розділи:

1. Співробітники
2. Книги
3. Продажі

Також є окремий розділ зі звітами.


Що вміє програма
================

Співробітники:
- додати співробітника;
- показати список;
- переглянути інформацію;
- редагувати;
- видаляти.

Книги:
- додати книгу;
- показати список;
- переглянути інформацію;
- редагувати;
- видаляти.

Продажі:
- створити продаж;
- показати список продажів;
- переглянути продаж;
- редагувати;
- видаляти.

Перед створенням продажу програма перевіряє, чи існує співробітник і книга.

Також програма перевіряє введені дані:
- дату;
- email;
- телефон;
- ціни;
- ID записів.

Якщо ввести неправильні дані, програма показує помилку і не падає.


База даних
==========

Для зберігання даних використовується PostgreSQL.

Основні таблиці:

employees
- співробітники;

books
- книги;

sales
- продажі.

Продаж пов'язаний зі співробітником і книгою через їх ID.

Тобто у продажі зберігається:
- хто продав;
- яку книгу продав;
- дата продажу;
- фактична ціна продажу.


Прибуток
========

Прибуток рахується так:

фактична ціна продажу - собівартість книги

Наприклад:

Собівартість: 300 грн
Продали за:   500 грн

Прибуток:     200 грн


Звіти
======

У програмі є такі звіти:

- продажі за конкретну дату;
- продажі за період;
- продажі конкретного співробітника;
- найбільш продавана книга;
- найуспішніший продавець;
- сумарний прибуток;
- популярний автор;
- популярний жанр.

Також звіти можна експортувати у CSV.


Що потрібно для запуску
=======================

Потрібно:

- Python 3;
- PostgreSQL;
- запущений PostgreSQL Server.

PostgreSQL повинен бути запущений, тому що всі дані програми
зберігаються саме в базі даних.

Python підключається до PostgreSQL і через SQL отримує або записує дані.

Якщо PostgreSQL не запущений, програма не зможе працювати з базою.


Запуск PostgreSQL на macOS
==========================

Якщо PostgreSQL встановлений через Homebrew:

brew services start postgresql@17

Перевірити:

brew services list


Як запустити проєкт
===================

1. Відкрити Terminal.

2. Перейти у папку проєкту:

cd book_sales_exam

3. Запустити:

python3 start_exam.py


Що робить start_exam.py
=======================

start_exam.py потрібен для простого запуску всього проєкту.

Він автоматично:

1. перевіряє PostgreSQL;
2. запускає PostgreSQL, якщо потрібно;
3. підключається до PostgreSQL;
4. перевіряє або створює базу book_sales;
5. створює файл .env;
6. створює Python-середовище .venv;
7. встановлює потрібні бібліотеки;
8. створює таблиці;
9. додає тестові дані;
10. запускає основну програму.

При першому запуску може попросити:

PostgreSQL admin user [postgres]:
PostgreSQL password:

Якщо користувач postgres, у першому полі можна просто натиснути Enter.

Після цього потрібно ввести пароль PostgreSQL.

При введенні пароля символи в Terminal не показуються.
Це нормально.


Основний запуск програми
========================

Сам застосунок запускається через:

python3 main.py

Але простіше використовувати:

python3 start_exam.py


Структура проєкту
=================

main.py
- запускає основну програму.

cli.py
- меню програми.

database.py
- підключення до PostgreSQL.

config.py
- налаштування підключення.

repositories/
- робота з таблицями та SQL-запитами.

services/
- звіти.

utils/
- перевірка даних та допоміжні функції.

sql/
- SQL для створення таблиць та тестових даних.

export/
- сюди зберігаються CSV-файли.

seed.py
- додає тестові дані.

start_exam.py
- автоматично готує і запускає весь проєкт.


Головне меню
============

Після запуску відкривається меню:

1. Співробітники
2. Книги
3. Продажі
4. Звіти
0. Вихід
